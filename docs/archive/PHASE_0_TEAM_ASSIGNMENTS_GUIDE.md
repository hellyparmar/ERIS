## 🔄 HOW TO ASSIGN ON GITHUB

### Step-by-Step Instructions

1. **Open GitHub Issues**
   - Go to: https://github.com/hellyparmar/R-DIOS/issues
   - You should see all 12 issues listed

2. **For Each Issue:**
   - Click on the issue number or title
   - On the right side, find "Assignees"
   - Click on "Assignees"
   - Start typing the team member's GitHub username
   - Select from the dropdown
   - Issue is now assigned

3. **Verify Assignment**
   - Return to issues list
   - Confirm assignee name appears next to issue title

### Quick Assignment Keyboard Shortcut
- Click issue → press `A` → type name → select → done
