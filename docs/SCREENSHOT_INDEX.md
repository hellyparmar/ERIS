## Usage Guidelines

### For Thesis Document

- Use high-resolution versions (1920x1080)
- Include captions with annotations
- Reference by screenshot number
- Place in relevant chapters as indicated

### For Presentation Slides

- Crop to focus on key elements
- Add callout arrows for emphasis
- Use consistent annotation style
- Maintain aspect ratio

### For Portfolio

- Select 8-10 most impactful screenshots
- Prioritize visual appeal
- Include brief descriptions
- Highlight technical achievements
