┌──────────────────────────────────────────────────────────────────────────────┐
│ DATABASE SCHEMA (Phase 2)                                                    │
└──────────────────────────────────────────────────────────────────────────────┘

GSTConfiguration (Tax Settings)
   ├─ business_id (PK)
   ├─ gstin, business_name
   ├─ financial_year, gst_registration_date
   ├─ intra_state_cgst, intra_state_sgst, inter_state_igst
   └─ Relationships: 1-to-Many with Invoice

Invoice (Sales Documents)
   ├─ invoice_id (PK)
   ├─ business_id, customer_id, customer_name
   ├─ invoice_number (unique), payment_status
   ├─ total_taxable, total_tax, total_amount
   ├─ Indexes: business_id, customer_id, invoice_number
   └─ Relationships: 1-to-Many with InvoiceLineItem, InvoicePayment

InvoiceLineItem (Line Details)
   ├─ line_item_id (PK)
   ├─ invoice_id (FK)
   ├─ product_name, quantity, unit_price
   ├─ tax_rate, line_total, cgst_amount, sgst_amount
   └─ Relationships: Many-to-One with Invoice

InvoicePayment (Payment Tracking)
   ├─ payment_id (PK)
   ├─ invoice_id (FK)
   ├─ amount, payment_date, payment_method
   └─ Relationships: Many-to-One with Invoice

CustomerCredit (Credit Accounts)
   ├─ credit_id (PK)
   ├─ business_id, customer_id, customer_name
   ├─ credit_limit, used_credit, credit_score, credit_status
   ├─ on_time_payments, late_payments, missed_payments
   └─ Relationships: 1-to-Many with CreditTransaction, CreditReminder

CreditTransaction (Transaction History)
   ├─ transaction_id (PK)
   ├─ customer_id (FK)
   ├─ transaction_type (CREDIT/PAYMENT)
   ├─ amount, invoice_id, due_date, description
   ├─ is_on_time, is_late, is_missed
   └─ Relationships: Many-to-One with CustomerCredit

CreditReminder (Payment Reminders)
   ├─ reminder_id (PK)
   ├─ customer_id (FK)
   ├─ invoice_id, due_date, amount_due
   ├─ reminder_type, channels, status
   └─ Relationships: Many-to-One with CustomerCredit
